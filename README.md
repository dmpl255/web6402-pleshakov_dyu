# Лабораторная работа №3

## Список реализованных функций

| Функция | Назначение |
| --- | --- |
| `isInteger(n)` | Проверяет, является ли число целым, через побитовые операторы |
| `even()` | Возвращает массив чётных чисел от 2 до 20 включительно |
| `sumTo(n)` | Сумма чисел от 1 до `n` с помощью цикла |
| `recSumTo(n)` | Сумма чисел от 1 до `n` с помощью рекурсии |
| `factorial(n)` | Факториал числа `n` |
| `isBinary(n)` | Проверяет, является ли число степенью двойки |
| `fibonacci(n)` | N-е число Фибоначчи |
| `getOperationFn(initialValue, operatorFn)` | Возвращает функцию-накопитель с внутренним состоянием |
| `sequence(start, step)` | Создаёт независимый генератор арифметической прогрессии |
| `deepEqual(a, b)` | Глубокое сравнение значений и объектов |
